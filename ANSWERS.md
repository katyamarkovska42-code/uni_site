# Відповіді

## Вибір факультету
Факультет природничих наук. Це один з небагатьох факультетів, що не має сучасного
сайту зі зручним інтерфейсом. Більше того, там розміщена застаріла інформація (в тому числі
про освітні програми). Особливо доречно оновити саме його, щоб збільшити кількість вступників 
саме на спеціальності цього факультету, оскільки уже декілька років факультет має недобір.

## 3. Кількість місць
Значення «до 4» зберігаємо як число 4 (максимальна кількість місць). Слово «до»
при цьому втрачається. Я обрала цей варіант, бо він найпростіший, а окреме поле
«точно / максимум» ускладнило б модель без потреби. З «2 місця» та «1 місце»
береться число з тексту.

## 4. Статус прийому
Ні, окреме поле зберігати не варто. Статус повністю випливає з дедлайну і
сьогоднішньої дати, тому поле дублювало б інформацію. Збережений статус
застарівав би сам, бо дедлайн минає без жодної дії, і сайт міг би показувати
«Прийом триває» для програми, дедлайн якої вже минув. Тому статус обчислюється
в коді (`is_open`). Окреме поле мало б сенс лише тоді, коли деканат закриває
прийом достроково.

## 5. Відкат із втратою даних
- `0005_fill_seats_number`: втрачається початкове формулювання місць («2 місця»
  стає «2», «до 4» стає «4»).
- `0003_split_university_country`: втрачається початковий розділювач країни
  (дужки, дефіс, кома), після відкату скрізь кома.
- `0002_load_exchange_programs`: завантаженs рядкb видаляються, правки,
  зроблені після завантаження, втрачаються.
- `0001_initial`: видаляється вся таблиця з усіма програмами.
